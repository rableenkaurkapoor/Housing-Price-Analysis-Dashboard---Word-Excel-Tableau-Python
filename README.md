# House Price Analysis Dashboard

## Project Overview
This project analyzes house pricing trends, property characteristics, and location-based price variations using Excel, Tableau and Python. Interactive dashboards and visualizations were created to identify factors influencing house prices and support business-focused decision-making.

## Key Insights
- Square footage strongly impacts house prices
- Location significantly affects property value
- Most properties fall within lower-to-mid price ranges
- Geographic analysis highlights expensive cities and regions
- Data cleaning improved reporting accuracy and analysis quality

---

## Excel Analysis
- Created KPI summaries and price distribution analysis
- Built charts for city-wise and category-wise comparisons
- Visualized property pricing trends and business insights

---

## Tableau Analysis
- Developed interactive dashboards and geographic visualizations
- Analyzed average property prices across locations
- Created business-focused visual storytelling dashboard

---

## Python Analysis
- Performed data cleaning and exploratory data analysis (EDA)
- Built visualizations using Python libraries
- Identified trends, correlations, and pricing patterns

## Conclusion
This project demonstrates a complete multi-tool data analysis workflow using Excel, Tableau, Power BI, and Python to transform raw housing data into meaningful business insights and visual dashboards.
